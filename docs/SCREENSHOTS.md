# Screenshots

Only genuine application output should be added to this repository. Do not use mock successful analysis as if it were a real run.

Recommended files under `docs/images/`:

| File | Suggested content |
|---|---|
| `01-price-anomaly.png` | ticker, price chart and one detected anomaly |
| `02-thesis.png` | business model, core thesis and a material condition |
| `03-evidence.png` | expanded evidence/source section for that condition |
| `04-sec-status.png` | an actual SEC signal, partial result, or access-limit state |

Before committing an image, check that it does not expose:

- API keys or tokens,
- SEC contact email if you do not want it public,
- personal filesystem paths,
- brokerage/account information,
- unrelated browser tabs or notifications.

If a screenshot uses a saved analysis rather than a fresh run, label it accordingly. If SEC access is limited or evidence is missing, keep that state visible rather than editing the image to imply success.
