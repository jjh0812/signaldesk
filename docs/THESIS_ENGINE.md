# 투자 논리 엔진 · v1.2.0

## 사용 흐름
티커 조회 후 **투자 논리 자동 분석 · 최대 2회**를 누른다. 동의하면 같은 공개자료를 이용해
사업 구조, 핵심 투자 논리, 중요한 조건을 정리한다. 별도 재무 입력이나 기업별 코딩은 없다.
조건 충족은 주가 상승/하락의 보장이 아니며 자동 주문 기능은 없다.

## 구현

1. **회사 식별 + 웹 조사**: 기존 설정 모델이 공개자료를 검색하며, 원 발행사와 최신 사업 공시,
   후속 IR 업데이트를 우선한다. 여섯 공통 축(고객, 제품, 실행, 수익성, 규제, 자금) 중 중요한
   1~3개만 고른다. 이 단계는 자유서술형 한국어 보고서로 출력하며 문단별 인용을 요청한다.
2. **서버 출처 정리**: 실제 웹 도구의 반환 URL/인용 메타데이터를 모아 S1... 출처 목록을 만든다.
   최종 답변 문단과 인용 위치를 연결해 E1... 근거 문단을 만든다. 진행 메시지/내부 추론은
   사용하지 않는다. 원문을 직접 다운로드해 사실을 대조하는 검증과는 다르다.
3. **표준 형식 정리**: 추가 웹 도구 없이 위 메모·출처·근거 문단만 모델에 제공하고 JSON Schema로
   구조화한다. 각 사실/논리는 서버 근거 ID를 참조해야 한다. 입력에 없는 회사별 문구를
   고정해 넣지 않는다. SEC 이메일·API 키·로컬 경로·스냅샷 토큰은 입력에 포함하지 않는다.
4. **검사 후 표시**: 다른 티커, 근거 ID 누락, 이미 완료된 이정표, 일반론적인 조건, 중복과
   과대 길이 등은 제외한다. 한 항목이 실패해도 다른 유효한 항목은 보존한다. 전체 JSON이
   잘렸거나 거절/미완료이면 임의 수리하지 않는다. 핵심 논리가 없으면 빈 값을 인정한다.

## 비용과 복구

새 분석은 최대 **2 API 시도 + 첫 요청에서 최대 8 웹 도구 사용**이다. 두 단계는 각각 기존
20회/일 공동 한도에 기록한다. API 실패도 비용이 들 수 있다. 자동 유료 재시도는 하지 않는다.
첫 단계 초안은 두 번째 호출 전에 저장한다. 정리 실패 시 초안을 볼 수 있으며, 사용자 동의로
**정리만 1회** 다시 요청할 수 있다. 동일 기업·미국 동부 조사일·6시간 이내 초안만 재사용한다.
초안 읽기와 결과 읽기는 무료이고 서버 외부 요청을 하지 않는다. 새 분석 버튼은 새 조사이다.
이전 유효 보고서가 있으면 실패/전체 근거 미확보 결과로 덮어쓰지 않는다.

## SEC 감시와 구분

투자 논리의 자금 위험은 **AI 조건부 해석**이고, Dilution Watch는 **SEC 문구·서류 탐지**이다.
둘은 독립적이다. SEC 쿨다운이 투자 논리 버튼까지 비활성화시키지 않는다. 다만 한 작업 실행
중에는 중복 작업을 막는 공통 잠금을 사용한다. 접근 거절은 우회하지 않는다. 신규403/429는
최소600초와 Retry-After 중 긴 시간을 기다린다. 과거 쿨다운은 기존 기한을 그대로 사용한다.
예상 희석률, 미공개 증자 예측, 앱을 닫아도 계속되는 푸시 감시는 구현하지 않았다.

## 한계

특정 산업/회사에서 어느 조건을 골랐는지와 출처의 실제 적합성은 모델 성능/검색 결과에 좌우된다.
검사는 **형식과 근거 연결**이고 독립 팩트체크가 아니다. 실제 계약 수치·단계·발표일·수익 구조는
원문을 대조해야 한다. 최근 공시를 못 찾거나 갱신을 놓칠 수 있고, 모든 미국 티커의 식별이나
완전한 투자 논리를 보장하지 않는다. 일반적으로 중요한 거시/가치평가 조건도 빠질 수 있다.

## 주요 파일
- `backend/app/thesis_engine.py`: 두 단계 요청, 출처 문단, 정규화, 부분 결과, 초안/보고서 캐시.
- `backend/app/watch_api.py`: 명시적 최대 호출 수/초안 재사용 동의, 상태·진행 단계 API.
- `frontend/components/StockWatch.jsx`: 한 화면 투자 논리, 조건, 자금 위험, 별도 SEC 오류.
- `backend/tests/test_thesis120.py`, `frontend/lib/thesis.test.mjs`: 모의 업종·오류·동의·출처 검사.
